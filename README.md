# 闸对

中文名：**闸对** · 前缀 `gatetwin` · 端口 **6500 / 11500**

## 骨架

**刷卡点装载 → 同卡进站出站成对物化 → 缺腿/异向/超时旁路 → 行程账与刷卡点互证**

皮：地铁/公交闸机刷卡。去皮是 **OD 成对管道 + 开腿态 + 旁路 + 行程贯验**，不是票务售票 CRUD、不是乘车码业务页、不是日结封账。

## 冒烟

```bash
docker compose up -d --build
# http://127.0.0.1:6500
# 刷卡流 → 灌「成对样例」→ 看开腿账/行程账 → 再灌「缺腿超时样例」「出站孤儿样例」→ 行程贯验
# 多卡隔离 → 灌「多卡隔离-A进B出」看跨卡旁路 → 灌「多卡隔离-并发双卡」看两端卡号一致 → 行程贯验
```

## 主链对象

| 对象 | 作用 |
| --- | --- |
| 刷卡点 | 带卡号/站点/方向/事件时的进出闸事件 |
| 开腿账 | 已进站尚未出站的在途开腿 |
| 行程账 | 进站+出站成对后的正式行程 |
| 旁路匣 | 缺腿超时 / 出站孤儿 / 重复进站等 |
| 行程贯验 | 成对刷卡 ↔ 行程笔数 ↔ 旁路命运互证 |
| 多卡隔离 | 跨卡出站判定:出站卡 / 候选开腿卡 / 批命运 / 证据 / valid |

## 多卡串扰隔离(已落独立主链路)

全局架构:**甲·跨卡出站旁路**(只贯彻一种;不采用乙·拒整批)。

- 出站匹配开腿只查**本卡**在途腿(`查在途开腿`),候选永不越卡;并发装载每卡独立在途栈,不串栈。
- 卡A在途时灌卡B出站 → B同票进旁路匣(原因=`跨卡无开腿`),**A开腿仍在途**,批内其他合法事件继续,批命运=`继续`。
- 行程写闸(`成对写闸`):写行程账前断言两端卡号相等,不等即拒写+同票旁路+记 `valid=0`;写后读回双端刷卡复核。失败闭可核。
- 只读接口 `GET /api/多卡隔离`:出站卡、候选开腿卡、批命运、旁路或回滚证据、valid;`GET /api/多卡隔离/架构` 给全局口径。
- 装载 `POST /api/多卡隔离/装载` 与 `POST /api/多卡隔离/装载/夹具?名=…`;贯验新增:行程两端卡号互查 + 隔离判定 valid 全通。
- 夹具:`多卡隔离-A进B出`(卡61在途+卡62旁路无行程)、`多卡隔离-A进A出`(须成对)、`多卡隔离-并发双卡`(交错进64/进65/出65/出64,两端卡号不得不一致)。
